# How to use

Ниже базовый flow для нового пользователя.

## 1) Открыть приложение

Перейдите на [zeroplay.space](https://zeroplay.space/).

## 2) Ознакомиться с доступными сценариями

- Посмотрите активные возможности в интерфейсе.
- Сверьте основные параметры и потенциальный результат.

## 3) Выбрать понятный сценарий

- Начинайте с простых кейсов.
- Не используйте стратегию, которую не можете объяснить себе в двух-трех шагах.

## 4) Работать дисциплинированно

- Заранее фиксируйте лимиты.
- Избегайте эмоциональных решений.
- Сохраняйте единый подход к оценке сценариев.

## Важно

Материал в этом разделе носит информационный характер и не является финансовой рекомендацией.
