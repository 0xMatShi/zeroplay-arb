# What is ZeroPlay

`ZeroPlay` - это приложение для пользователей, которые хотят работать с рыночными возможностями в формате риск-ориентированного трейдинга, а не эмоциональных ставок.

## Основная идея

- Платформа помогает быстро оценивать сценарии и принимать решения на основе математики.
- Пользователь видит структуру возможных исходов и может действовать системно.
- Фокус на дисциплине, скорости и понятной логике работы.

## Для кого продукт

- Для пользователей, которым нужен инструмент с прозрачной логикой действий.
- Для тех, кто предпочитает структурированный процесс вместо случайных решений.

- Внутренняя архитектура и закрытые механики
