# Terms

Ниже базовая версия условий использования `ZeroPlay`.

## 1. Принятие условий

Используя сервис, пользователь подтверждает согласие с настоящими условиями.

## 2. Доступ к сервису

- Сервис может изменяться, ограничиваться или обновляться без предварительного уведомления.
- Пользователь использует сервис на собственный риск.

## 3. Обязанности пользователя

- Использовать сервис только в законных целях.
- Не нарушать работу сервиса, не пытаться получить несанкционированный доступ.
- Самостоятельно проверять применимость сервиса в своей юрисдикции.

## 4. Интеллектуальная собственность

Контент и элементы сервиса принадлежат правообладателю, если иное не указано отдельно.

## 5. Изменения условий

Условия могут обновляться. Актуальная версия публикуется в документации на `docs.zeroplay.space`.
