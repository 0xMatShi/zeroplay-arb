# Privacy

Ниже базовые принципы обработки данных в `ZeroPlay`.

## Какие данные могут обрабатываться

- Технические данные сессии (например, тип устройства, браузер).
- Служебные данные, необходимые для стабильной работы сервиса.
- Данные коммуникации, если пользователь обращается в поддержку.

## Для чего используются данные

- Для работы и улучшения продукта.
- Для безопасности и предотвращения злоупотреблений.
- Для коммуникации с пользователем по сервисным вопросам.

## Базовые принципы

- Минимизация объема данных.
- Ограничение доступа к данным внутри команды.
- Применение разумных мер защиты данных.

## Обновления политики

Политика может обновляться. Текущая версия всегда доступна на `docs.zeroplay.space`.
