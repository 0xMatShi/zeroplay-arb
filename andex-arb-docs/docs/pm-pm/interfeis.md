# Интерфейс

Режим `PM <> PM` состоит из двух основных зон:

- левая панель;
- основная область.

---

## Левая панель

Слева находятся все настройки режима:

- переключение ARB MODE
- Min ROI
- Sort
- Platforms

Через эту панель вы задаете, какие `PM <> PM`-связки будут отображаться в выдаче.

---

## Основная область

Справа находится список найденных арбитражных возможностей между prediction market платформами.

Каждая карточка показывает одну связку между двумя **PM**-площадками. Внутри карточки отображается:

- событие
- две стороны связки
- платформы
- текущий профит в процентах и в деньгах
- информация по времени нахождения и проверки
