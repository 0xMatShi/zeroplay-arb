# Фильтры

В режиме `PM <> PM` фильтры управляют тем, какие связки между prediction market платформами будут показаны в выдаче.

## Min ROI

Фильтр Min ROI задает минимальную доходность для показа карточек.

Если вы выставили, например, 5%, в списке будут отображаться только те связки, где доходность от 5% и выше.
Все возможности с ROI ниже этого значения показываться не будут.

Этот фильтр нужен, чтобы сразу отсечь слабые спреды и оставить только те связки, которые подходят вам по доходности.

## Sort: Profit % / Profit $

Profit % - карточки сортируются по процентной доходности;

Profit $ - карточки сортируются по абсолютному профиту в долларах.

Этот фильтр не убирает карточки из списка, а только меняет порядок их отображения.

## Platforms

Фильтр Platforms позволяет выбрать, между какими prediction market платформами сервис будет искать и показывать арбитражные связки. Если платформа не выбрана, связки с ее участием не будут отображаться в выдаче.

Этот фильтр нужен, чтобы оставить только те площадки, с которыми вы работаете.
