# Интерфейс

Режим `PM <> BK` состоит из трех основных частей:

- верхняя панель;
- левая панель управления;
- основная область со списком найденных связок.

## Верхняя панель

В верхней части экрана находятся общие элементы интерфейса:

- статус сканирования
- переключение языка
- настройка звука
- личный кабинет

Эта зона нужна для общего состояния сервиса и базовых действий, но не участвует в настройке самих связок.

## Левая панель управления

Слева находится вся основная настройка режима `PM <> BK`. Здесь происходит настройка:

- переключение режима арбитража
- параметры отбора
- формат отображения
- настройка типы связок, сортировка, пары площадок и категории

Именно левая панель определяет, какие возможности будут показаны в основной области.

## Основная область

Здесь отображаются найденные арбитражные возможности по текущим настройкам.

Каждая карточка в списке - это отдельная найденная связка. В ней собрана краткая информация о событии, платформах и результате расчета.
