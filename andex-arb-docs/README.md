# ZeroPlay docs

Документационный подпроект на [Docusaurus](https://docusaurus.io/) для `ZeroPlay`.

## Установка

```bash
npm install
```

## Локальный запуск

```bash
npm start
```

После запуска сайт доступен на `http://localhost:3000`.

## Целевые домены

- Приложение: `https://zeroplay.space`
- Документация: `https://docs.zeroplay.space`

## Сборка статики

```bash
npm run build
```

Собранный статический сайт находится в `build`.

## Локальная проверка сборки

```bash
npm run serve
```
