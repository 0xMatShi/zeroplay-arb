# SubLine docs

Документационный подпроект на [Docusaurus](https://docusaurus.io/) для `SubLine`.

## Установка

```bash
npm install
```

## Локальный запуск

```bash
npm start
```

После запуска сайт доступен на `http://localhost:3000`.

## Целевые домены

- Приложение: `https://subline.space`
- Документация: `https://docs.subline.space`

## Сборка статики

```bash
npm run build
```

Собранный статический сайт находится в `build`.

## Локальная проверка сборки

```bash
npm run serve
```
